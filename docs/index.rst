Documentation du package ``simulateur``
=======================================

``simulateur`` simule le déplacement de véhicules sur un réseau routier modélisé
par un graphe orienté : les intersections sont les nœuds, les routes les arêtes.
Chaque véhicule suit le trajet le plus rapide (algorithme de Dijkstra) et sa vitesse
diminue lorsque la route se remplit.
